# 2 Hour Attention System — Landing Page

Landing page for the **2 Hour Attention System** course by Wiser with Akshay.

## Project Structure

```
├── public/
│   ├── index.html          # Landing page
│   ├── Wiserwithakshay.png
│   ├── Ak47unfiltered.png
│   └── Statistic-Image.png
├── server.js               # Express server
├── package.json
├── .gitignore
└── README.md
```

## Run Locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

For development with auto-reload:

```bash
npm run dev
```

## Deploy

Works on any Node.js host — Railway, Render, Heroku, etc.  
Set the start command to `npm start`. No environment variables needed.
