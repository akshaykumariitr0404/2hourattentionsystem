# 2 Hour Attention System — Landing Page

Landing page for the **2 Hour Attention System** course by Wiser with Akshay.

## Project Structure

```
├── index.html          # Landing page (all CSS inline, no dependencies)
├── Wiserwithakshay.png
├── Ak47unfiltered.png
├── Statistic-Image.png
├── server.js           # Express server (for Node.js hosting)
├── package.json
├── .gitignore
└── README.md
```

## Run Locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

For development with auto-reload:

```bash
npm run dev
```

## Deploy

**GitHub Pages (free):**
1. Push this folder's contents to a GitHub repo
2. Go to Settings → Pages → Source: `main` branch, `/ (root)` folder → Save
3. Your site goes live at `https://yourusername.github.io/repo-name`

**Node.js hosts (Railway, Render, Heroku):**
Connect the GitHub repo and set start command to `npm start`. No environment variables needed.
